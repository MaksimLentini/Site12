🚀 MegaChat

Мессенджер нового поколения с реальной SQLite базой данных. Нажмите кнопку чтобы скачать полный проект в ZIP архиве со всеми файлами.

Подготовка файлов...

📋 Инструкция после скачивания:

  1. Распакуйте megachat.zip в любую папку
  2. Откройте терминал в папке megachat
  3. Выполните: npm install
  4. Перейдите в сервер: cd server
  5. Установите зависимости: npm install
  6. Запустите сервер: npm start
  7. В ДРУГОМ терминале: npm run dev
  8. Откройте браузер: http://localhost:5173
  9. Зарегистрируйтесь (первый пользователь = superadmin)
⚠️ Важно: Для работы нужен Node.js 18+ и npm. База данных SQLite создаётся автоматически в server/data/messenger.db

## 🛠 Как это работает

### Серверная часть (Socket.IO)

Сервер отправляет события всем подключённым клиентам при изменениях в базе данных:

```javascript
// Создание поста
io.emit('post:created', newPost);

// Лайк поста
io.emit('post:liked', { postId, likes, userId });

// Новое сообщение
io.to(`chat_${chatId}`).emit('new_message', newMessage);

// Реакция на сообщение
io.emit('message:reaction', { messageId, userId, emoji });

// Создание видео
io.emit('video:created', newVideo);

// Создание музыки
io.emit('music:created', newTrack);

// Создание сторис
io.emit('story:created', newStory);

// Создание чата
allMembers.forEach(memberId => {
  io.to(`user_${memberId}`).emit('chat:created', newChat);
});
```

### Клиентская часть (React)

Клиенты слушают события и обновляют UI:

```typescript
// Подписка на создание поста
useSocketEvent('post:created', (newPost) => {
  setPosts(prev => [newPost, ...prev]);
});

// Подписка на лайки
useSocketEvent('post:liked', ({ postId, likes }) => {
  setPosts(prev => prev.map(p => 
    p.id === postId ? { ...p, likes_count: likes } : p
  ));
});

// Подписка на новые сообщения
useSocketEvent('new_message', (newMsg) => {
  if (selectedChat && newMsg.chat_id === selectedChat.id) {
    setMessages(prev => [...prev, newMsg]);
  }
});
```

## 🔌 Подключение к Socket.IO

### Автоматическое подключение

При входе в систему клиент автоматически подключается к Socket.IO:

```typescript
useEffect(() => {
  if (auth.isLoggedIn()) {
    auth.getCurrentUser().then(u => {
      setUser(u);
      // Подключаемся к Socket.IO
      const token = localStorage.getItem('megachat_token');
      if (token) {
        connectSocket(token);
      }
    });
  }
}, []);
```

### Отключение

При выходе из системы Socket.IO автоматически отключается:

```typescript
useEffect(() => {
  if (!user) {
    disconnectSocket();
  }
}, [user]);
```

## 📊 События Socket.IO

### Сервер → Клиент

| Событие | Описание | Данные |
|---------|----------|--------|
| `post:created` | Новый пост создан | `Post` объект |
| `post:liked` | Пост получил лайк | `{ postId, likes, userId }` |
| `new_message` | Новое сообщение в чате | `Message` объект |
| `message:reaction` | Реакция на сообщение | `{ messageId, userId, emoji }` |
| `video:created` | Новое видео загружено | `Video` объект |
| `music:created` | Новый трек загружен | `MusicTrack` объект |
| `story:created` | Новая сторис создана | `Story` объект |
| `chat:created` | Новый чат создан | `Chat` объект |

### Клиент → Сервер

Клиент может отправлять события через `socket.emit()`:

```typescript
import { getSocket } from './socket';

const socket = getSocket();
socket?.emit('custom_event', { data: 'value' });
```

## 🔧 Настройка

### Сервер

Socket.IO уже настроен в `server/server.js`:

```javascript
import { Server } from 'socket.io';

const io = new Server(server, { 
  cors: { 
    origin: '*',
    methods: ['GET', 'POST']
  } 
});
```

### Клиент

Socket.IO клиент настроен в `src/socket.ts`:

```typescript
import { io } from 'socket.io-client';

export function connectSocket(token: string) {
  socket = io('http://localhost:3001', {
    auth: { token },
    transports: ['websocket', 'polling']
  });
}
```

## 🚀 Запуск

### 1. Запустите сервер

```bash
cd server
npm start
```

Сервер запустится на `http://localhost:3001`

### 2. Запустите фронтенд

```bash
npm run dev
```

Фронтенд запустится на `http://localhost:5173`

### 3. Откройте в двух браузерах

Откройте `http://localhost:5173` в двух разных браузерах (или в режиме инкогнито).

### 4. Войдите под разными пользователями

Зарегистрируйте двух пользователей и войдите под ними в разных браузерах.

### 5. Тестируйте real-time

- Создайте пост в одном браузере → он появится в другом
- Отправьте сообщение → оно появится у обоих
- Поставьте лайк → счётчик обновится у обоих

## 🐛 Отладка

### Проблема: События не приходят

**Решение:**
1. Проверьте, что сервер запущен
2. Проверьте консоль браузера на ошибки Socket.IO
3. Убедитесь, что токен авторизации действителен
4. Проверьте, что клиент подключён к Socket.IO

### Проблема: Дублируются сообщения

**Решение:**
1. Проверьте, что не создаётся несколько подключений
2. Используйте `useSocketEvent` хук правильно
3. Убедитесь, что при размонтировании компонента события отписываются
